# 网格辅助建造 · 平整地面 + 网格吸附(网格球)设计方案与计划

> 目标:像戴森球计划那样,**在放置建筑时显示网格,并严格按网格吸附放置**;网格必须落在**相对平整的面**上。
> 玩法:先"平整"出一块平地(建造平台),放建筑时**动态根据该平地生成网格球**,在其中整齐建造;
> 网格外(或未整平处)**仍可自由放置**,只是不那么整齐。
>
> 铁律沿用:网格数学核心零 three.js(可 node 无头测试);数据驱动;复用 `Anchor{dir,yaw}`、`sphere.js` 球面数学、
> `terrain.js` 的 `level` 整平编辑、`worldMatrix` 落地矩阵、InstancedMesh 渲染。

---

## A. 现状与关键结论

### A.1 放置链路(改动面极小)
- 点击 → `anchor.pick` 得到球面单位方向 `dir` → `placeBuilding(world, ctx, id, dir, yaw)` → 存 `Anchor{dir, yaw}`。
- 落地: `worldMatrix(dir, yaw, planet)` 用 `radius + heightAt(dir)·maxHeight` 定位,`yaw` 在切平面里转朝向。
- **要"守规矩",只需在 `placeBuilding` 之前把 `dir`/`yaw` 吸附到网格**;下游(渲染/物流/存档)完全不改。

### A.2 地形已内置"整平"能力(关键利好)
`terrain.js` 的 `heightAt` 已支持两类运行时 `edits`:
- 减量式(默认): `{ pos, radius, depth, falloff }` —— 挖坑/抬升(采矿区用的是这个,碗形坑)。
- **整平式**: `{ type:'level', pos, radius, level, progress, falloff }` —— 把圆区内**高于 `level` 的地形削平到平面**,
  内侧 ~75% 完全平、外侧 25% 平滑过渡,`progress` 0→1 驱动。**此能力已写好但当前无人使用。**

> 注意:整平"**只挖不填**"(`leveled = h < level ? h : level`)。故 `level` 应取平整区内地形**最低点**,
> 才能把整块削到同一平面 → 真正的平地。

由此,"平地"不用新造轮子:创建一条 `level` 编辑即可。平地内 `heightAt` 恒为 `level` → 网格放置的建筑天然等高、整齐。

## B. 目标架构

```
平整地面(level 编辑) ──► BuildPad{ center, e, n, cell, radius, level, occupied }
                          │  进入放置模式时
                          ▼
                        渲染网格球(沿测地线的曲面方格) + 光标格高亮 + 建筑虚影预览
                          │  放置时
                          ▼
      dir 落在某 pad 内 ─► 吸附到格点 + 对齐朝向 + 占位检查(重叠则拒) ─► placeBuilding
      dir 在所有 pad 外 ─► 自由放置(保持现状)
```

- **BuildPad(建造平台)**:网格的载体。由"平整地面"动作产生,记录中心方向 `center`、切平面基 `{e,n}`、
  格边长 `cell`(世界单位)、平台角半径 `radius`、整平高度 `level`、已占格集合 `occupied`。
- **网格球**:以 `center` 建切平面基,格点经**球面指数映射**贴到曲面 → 局部方格、整体随曲率弯曲(即 DSP 网格球)。
- **吸附**:落在 pad 内的 `dir` → 对数映射求切平面坐标 → 就近取整到格点 → 指数映射回球面;`yaw` 量化到平台轴。
- **兼容**:pad 外自由放置(现状);pad 内强制吸附(可按修饰键临时解除)。改动是**叠加层**,不动现有链路。

## C. 核心:网格数学(`core/grid.js`,纯逻辑,可 node 测试)

### C.1 平台基
中心 `c`(单位方向),取辅助轴 `a = |c.y|<0.99 ? [0,1,0] : [1,0,0]`:
```
e = norm(cross(a, c))   // 东向切向
n = cross(c, e)         // 北向切向(右手系 {e, n, c})
```

### C.2 指数映射(格 → 方向) `cellToDir(pad, i, j)`
格点 `(i,j)`(整数或半格中心)对应切平面偏移 `t = (i·cell)·e + (j·cell)·n`(米):
```
d = |t|;  α = d / R                       // R = planet.params.radius
dir = d < ε ? c : norm(c·cosα + (t/d)·sinα)
```

### C.3 对数映射 + 吸附(方向 → 格 → 方向) `dirToCell` / `snapDir`
```
α = angle(c, dir)
tHat = norm(dir − c·(c·dir))              // 投影到 c 切平面
d = α · R
u = d·dot(tHat, e);  v = d·dot(tHat, n)
i = round(u/cell);   j = round(v/cell)    // 就近格点
snapped = cellToDir(pad, i, j)
```

### C.4 朝向量化 `snapYaw(pad, dir, quarter)`
建筑前向对齐平台轴:把默认 `worldMatrix` 在吸附点的前向,与"平台东向平移到该点"的夹角量化到 `k·90°`,
叠加玩家旋转 `quarter·90°`。小平台上 `yaw` 可近似取平台中心处一次算好复用。

### C.5 占位(多格建筑) `footprintCells` / `canPlace` / `markPlaced`
- `footprint:[w,h]`(格,默认 `[1,1]`);建筑锚点吸附到其覆盖格的中心。
- pad 维护 `occupied:Set("i,j")`;`canPlace` 检查覆盖格全空;`markPlaced`/`freePlaced` 增删。

> `grid.js` 零 three.js。测试 `test_grid.mjs`:格↔方向往返、就近吸附、近中心方格边长近似、朝向量化、占位增删/重叠拒绝、pad 外原样返回。

## E. 平整地面(BuildPad 生成)

`placeBuildPad(world, ctx, center, { cell, radius })`:
1. 在圆区内采样 `baseHeightAt` 若干点,取**最低值**作 `level`(保证只挖不填也能全平)。
2. 推 `{ type:'level', pos:center, radius, level, progress:1, falloff:'smooth' }` 进 `planet.params.edits`,
   `_buildNoise` + `_invalidateAffected` 刷新地形(与 `setDigZone` 同套路)。
3. 建 `BuildPad` 实体:`Anchor{dir:center}` + `BuildPad{center, e, n, cell, radius, level, occupied:{}}`,存空间索引。

> **整平来源(已定)**:先做**独立"平整地面"工具**(即时 `progress=1`),结构上把 `progress` 留作可动画字段;
> 后续可让挖机小队"整平"(改挖掘区为 `level` 编辑,`progress` 随作业增长)——届时复用同一 BuildPad。

## H. 设计决策 / 取舍

1. **只挖不填**:`level` 取平整区最低点 → 全平;高处削平、低处本就 ≤level。
2. **吸附只在 pad 内**:pad 外保持现状自由放置("不规整也能放");pad 内强制吸附,Alt 临时解除。
3. **网格仅放置模式显示**:与 DSP 一致,平时不渲染,减负担。
4. **改动面最小**:核心是新增纯模块 `core/grid.js` + `BuildPad`;放置只在最前插一层吸附;渲染是叠加网格层。
   不动物流/采矿/发动机/存档链路。
5. **cell 与建筑体量匹配**:cell 取基准值,多格建筑用 `footprint` 表达(不改建筑 mesh 尺寸)。
